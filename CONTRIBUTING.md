# Contributing

MEIKA Vox welcomes focused contributions to transcription infrastructure, data contracts, QA, research interoperability and privacy-aware workflows.

## Principles
1. Keep provider-specific logic behind adapters.
2. Preserve source lineage.
3. Never silently overwrite machine or human-reviewed data.
4. Do not commit real participant audio or productive transcripts.
5. Add tests for contract or pipeline changes.
6. Prefer small pull requests with a clear engineering decision.
